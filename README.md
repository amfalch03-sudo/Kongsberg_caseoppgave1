# Kraftberedskap

Frontend-demo av en norsk beredskapsplattform for registrering og koordinering av lokale energikilder under strømbrudd.

## Kjør lokalt

```bash
npm install
npm run dev
```

Appen bruker React, TypeScript, Vite, Tailwind CSS, React Router og React Leaflet med OpenStreetMap. Demo-data ligger lokalt i `src/data`, og nye registreringer lagres i `localStorage`.

## Demo-flyt

1. Åpne forsiden og forklar konseptet.
2. Registrer et aggregat.
3. Gå til beredskapskartet.
4. Aktiver krisemodus.
5. Velg et strømbehov.
6. Åpne en passende ressurs.
7. Reserver ressursen.
